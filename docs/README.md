# Documentación del Proyecto - WolfEnterprise

Estructura estandarizada de documentación técnica:
- `docs/prerequisites/`: Informes de viabilidad y compatibilidad de entorno local.
- `docs/architecture/`: Registros de Decisiones Arquitectónicas (ADRs) y diagramas.
- `docs/database/`: Diagrama Entidad-Relación (DER) y scripts DDL.
- `docs/design/`: Tokens de diseño, estilos y componentes UI.
- `docs/api/`: Especificaciones de contratos REST y esquemas de validación.
